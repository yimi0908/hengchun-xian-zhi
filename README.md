# 光绪恒春县志物产专题知识库

> 基于清光绪18年《恒春县志·物产》构建的古籍专题知识服务平台，完整实现数字化、数据化、知识化、平台化全流程。

## ✨ 项目简介
《光绪恒春县志物产专题知识库》是古籍专题知识库课程实验综合成果，以清光绪18年《恒春县志·物产》为唯一核心数据源，整合OCR文本清理、实体抽取、关系构建、知识图谱可视化等多实验成果，打造面向数字人文领域的方志物产知识服务平台。

平台收录38种物产元数据、189条命名实体、304条关系三元组，提供全文检索、分类浏览、交互式知识图谱、AI智能问答等功能，为古籍文献的数字化利用提供了完整的解决方案。

## 🚀 核心功能
- **🔍 全文检索**：支持物产名、别名、分类、用途、产地、形态、县志原文关键词检索，结果高亮显示
- **📚 物产浏览**：按"榖之属、蔬之属、瓜之属、果之属、药之属"等14个分类浏览全部物产
- **🌐 知识图谱**：交互式力导向图展示实体与关联关系，支持筛选、拖拽、缩放、节点详情弹窗
- **🤖 AI智能问答**：基于DeepSeek大模型，结合知识库内容，提供自然语言问答服务
- **👤 用户系统**：支持用户注册、登录功能
